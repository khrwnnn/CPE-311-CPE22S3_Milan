### Course Objectives

This course aims to provide students with an understanding of the role computation can play in solving problems. It also aims
to show students techniques and methods on writing application programs that allow them to solve simple problems using the
Python programming language. In addition, students will also learn how to visually represent the analysis of the problems and
its solutions using built-in libraries for analysis and visualization

</details>

<details>
<summary><strong>C.I.L.O.</strong></summary>

### Course Intended Learning Outcomes

1. Analyze the applications of data science and optimization techniques using Python.
2. Apply Python programming language to analyze data, solve a problem and present it to the stakeholders
3. Create and present a data storyboard that solves a problem aligned with United Nations SDG and other international indicators.
